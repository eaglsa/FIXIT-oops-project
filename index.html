1. Project Overview

FixIt is a command-line Java application where:

  • Students register, log in, raise maintenance complaints (electrical, plumbing, Wi-Fi, generic), and track their status.
  • Staff log in, view all complaints, update statuses, and see a dashboard.

The status of every complaint follows a strict workflow:

Workflow
REPORTED → IN_PROGRESS → RESOLVED
Skipping steps or going backwards is rejected with a clear error message.

cd C:\Users\...\Fixit

4. Architecture & Layers

The app is divided into 4 strict layers. Each layer may only talk to the layer directly below it.

🖥️ UI Layer  (CLIMenu.java) — Scanner, System.out live here. Calls services only.
↓
⚙️ Service Layer  (AuthService, ComplaintService) — Business rules. No SQL, no Scanner.
↓
🗄️ DAO Layer  (UserDAO, ComplaintDAO) — All SQL lives here. Uses PreparedStatement.
↓
🔌 DB Layer  (DBConnector) — Singleton. Opens & holds the MySQL connection.
✅ Why layers matter (viva answer)
Layering means each class has one job. If we change the database from MySQL to something else, only the DAO and DB layers change — the service and UI code stays the same. This is called Separation of Concerns.

5. OOP Concepts Map

OOP ConceptWhere it isWhat to say in the viva
Abstraction Complaint.java, User.java Abstract classes hide details. You can't do new Complaint() — you must use a concrete subclass.
Inheritance ElectricalComplaint, PlumbingComplaint, WifiComplaint, GenericComplaint, Student, Staff All four complaint types inherit from Complaint and reuse its fields and updateStatus() method.
Polymorphism getAssignedTeam(), getEstimatedResolutionHours(), getSafetyNote(), getRole() Same method name, different behaviour per subclass. The correct version is picked at runtime based on the actual object type.
Interface Updatable.java Defines a contract: any class that implements Updatable must provide updateStatus().
Encapsulation Every model class All fields are private. Outside code must use getters/setters — it can't directly change the data.
Singleton DBConnector.java Private constructor + static instance. Only one DB connection object ever exists in the whole app.
Factory ComplaintFactory.java The caller passes a ComplaintType; the factory decides which subclass to create. The caller doesn't need to know about subclasses.
Custom Exceptions exception/ package Four checked exceptions extend Exception, each with a clear message. Forces callers to handle errors.
Enum with Behaviour Status.canTransitionTo() Enums can have methods. The workflow rules live inside the enum itself instead of being scattered across the code.

package com.fixit;

import com.fixit.dao.ComplaintDAO;
import com.fixit.dao.UserDAO;
import com.fixit.db.DBConnector;
import com.fixit.service.AuthService;
import com.fixit.service.ComplaintService;
import com.fixit.ui.CLIMenu;
import java.sql.Connection;

/**
 * Application entry point.
 * Wires up all layers (db -> dao -> service -> ui) and starts the CLI menu.
 * If the database connection fails, a clear error is printed and the app exits.
 */
public class Main {

    public static void main(String[] args) {

        // 1. Check DB connection before doing anything else
        Connection conn = DBConnector.getInstance().getConnection();
        if (conn == null) {
            System.err.println("STARTUP ERROR: Could not connect to the database.");
            System.err.println("Check: MySQL is running, db.properties password is correct,");
            System.err.println("and you have run sql/schema.sql.");
            System.exit(1);
        }

        // 2. Wire up the layers (manual dependency injection)
        UserDAO          userDAO          = new UserDAO();
        ComplaintDAO     complaintDAO     = new ComplaintDAO();
        AuthService      authService      = new AuthService(userDAO);
        ComplaintService complaintService = new ComplaintService(complaintDAO);

        // 3. Hand control to the UI
        CLIMenu menu = new CLIMenu(authService, complaintService);
        menu.start();
    }
}

model/Status.java  Enum with Behaviour

package com.fixit.model;

/**
 * Workflow states. OOP: Enum with a method that encodes transition rules.
 * Allowed: REPORTED → IN_PROGRESS → RESOLVED only.
 */
public enum Status {

    REPORTED,
    IN_PROGRESS,
    RESOLVED;

    /**
     * Returns true only when moving from this status to 'next' is allowed.
     * OOP: behaviour inside an enum — not just a plain constant.
     */
    public boolean canTransitionTo(Status next) {
        return switch (this) {
            case REPORTED    -> next == IN_PROGRESS;  // only one legal step
            case IN_PROGRESS -> next == RESOLVED;     // only one legal step
            case RESOLVED    -> false;               // terminal state
        };
    }
}

model/Complaint.java  Abstract Class Interface impl

package com.fixit.model;
import com.fixit.exception.InvalidStatusTransitionException;
import java.time.LocalDate;

/**
 * Abstract base for all complaint types.
 * OOP: Abstraction, Encapsulation, Inheritance, Interface implementation.
 */
public abstract class Complaint implements Updatable {

    // Encapsulation: all fields are private
    private int       id;
    private String    description;
    private String    location;
    private Status    status;
    private int       raisedBy;
    private LocalDate dateReported;

    public Complaint(String description, String location, int raisedBy, LocalDate dateReported) {
        this.description  = description;
        this.location     = location;
        this.raisedBy     = raisedBy;
        this.dateReported = dateReported;
        this.status       = Status.REPORTED; // starts as REPORTED
        this.id           = 0;
    }

    // Implements Updatable interface. Validates transition before applying.
    @Override
    public void updateStatus(Status newStatus) throws InvalidStatusTransitionException {
        if (!this.status.canTransitionTo(newStatus)) {
            throw new InvalidStatusTransitionException(this.status.name(), newStatus.name());
        }
        this.status = newStatus;
    }

    // Abstract methods – subclasses MUST implement (Polymorphism)
    public abstract ComplaintType getType();
    public abstract String getAssignedTeam();
    public abstract int getEstimatedResolutionHours();
    public abstract String getSafetyNote();

    // Concrete method – shared by all subclasses
    public String getSummary() {
        return "  ID          : " + id + "\n"
             + "  Type        : " + getType().getDisplayName() + "\n"
             + "  Location    : " + location + "\n"
             + "  Status      : " + status + "\n"
             + "  Date        : " + dateReported + "\n"
             + "  Description : " + description;
    }

    // Getters
    public int       getId()           { return id; }
    public String    getDescription()  { return description; }
    public String    getLocation()     { return location; }
    public Status    getStatus()       { return status; }
    public int       getRaisedBy()     { return raisedBy; }
    public LocalDate getDateReported() { return dateReported; }
    public void      setId(int id)      { this.id = id; }
    public void      setStatus(Status s){ this.status = s; }
}

db/DBConnector.java  Singleton Pattern

package com.fixit.db;

/**
 * Singleton: only ONE instance can ever exist.
 * How: private constructor + private static instance + public static getInstance().
 */
public class DBConnector {

    private static DBConnector instance;   // the one-and-only instance
    private Connection connection;

    // Private constructor – nobody outside can call "new DBConnector()"
    private DBConnector() {
        InputStream input = getClass().getClassLoader().getResourceAsStream("db.properties");
        Properties props = new Properties();
        props.load(input);
        this.connection = DriverManager.getConnection(
            props.getProperty("db.url"),
            props.getProperty("db.user"),
            props.getProperty("db.password")
        );
    }

    // Public accessor – creates the instance once, returns it every time
    public static DBConnector getInstance() {
        if (instance == null) {
            instance = new DBConnector();  // created exactly ONCE
        }
        return instance;
    }

    public Connection getConnection() { return connection; }
}

service/ComplaintFactory.java  Factory Pattern

package com.fixit.service;

/**
 * Factory: caller passes a ComplaintType, factory picks the right subclass.
 * OOP: Factory pattern – hides "new XComplaint()" from the rest of the code.
 */
public class ComplaintFactory {

    private ComplaintFactory() {}  // never instantiate this

    public static Complaint create(ComplaintType type, String desc,
                                    String loc, int raisedBy, LocalDate date) {
        return switch (type) {
            case ELECTRICAL -> new ElectricalComplaint(desc, loc, raisedBy, date);
            case PLUMBING   -> new PlumbingComplaint(desc, loc, raisedBy, date);
            case WIFI       -> new WifiComplaint(desc, loc, raisedBy, date);
            case GENERIC    -> new GenericComplaint(desc, loc, raisedBy, date);
        };
    }

    // Used by ComplaintDAO to rebuild an object from a database row
    public static Complaint rebuild(int id, ComplaintType type, String desc,
                                      String loc, int raisedBy, LocalDate date, Status status) {
        Complaint c = create(type, desc, loc, raisedBy, date);
        c.setId(id);
        c.setStatus(status);
        return c;
    }
}

service/AuthService.java

public class AuthService {

    private final UserDAO userDAO;

    public AuthService(UserDAO userDAO) { this.userDAO = userDAO; }

    /** Login – throws AuthenticationException if credentials are wrong */
    public User login(String name, String password) throws AuthenticationException {
        User user = userDAO.findByNameAndPassword(name, password);
        if (user == null) throw new AuthenticationException("Invalid username or password.");
        return user;
    }

    /** Register – rejects blank name, short password, duplicate name */
    public User registerStudent(String name, String password) throws InvalidComplaintException {
        name = name.trim(); password = password.trim();
        if (name.isEmpty())          throw new InvalidComplaintException("Username cannot be blank.");
        if (password.length() < 4)  throw new InvalidComplaintException("Password must be at least 4 chars.");
        if (userDAO.nameExists(name)) throw new InvalidComplaintException("Username already taken.");
        return userDAO.createStudent(name, password);
    }
}

service/ComplaintService.java (key methods)

public class ComplaintService {

    public Complaint raiseComplaint(User user, ComplaintType type,
                                     String desc, String loc) throws ... {
        if (!"STUDENT".equals(user.getRole()))
            throw new UnauthorizedActionException("Only students can raise complaints.");
        if (desc.trim().length() < 5)
            throw new InvalidComplaintException("Description too short.");
        // Factory picks the right subclass:
        Complaint c = ComplaintFactory.create(type, desc, loc, user.getId(), LocalDate.now());
        complaintDAO.insert(c);
        return c;
    }

    public void updateStatus(User user, int complaintId, Status newStatus) throws ... {
        if (!"STAFF".equals(user.getRole()))
            throw new UnauthorizedActionException("Only staff can update complaint status.");
        Complaint c = complaintDAO.findById(complaintId);
        // updateStatus() validates via Status.canTransitionTo() – throws if invalid
        c.updateStatus(newStatus);
        complaintDAO.updateStatus(complaintId, newStatus, user.getId());  // transactional
    }
}

dao/UserDAO.java  PreparedStatement

public class UserDAO {

    public User findByNameAndPassword(String name, String password) throws SQLException {
        String sql = "SELECT id, name, role, password FROM users WHERE name = ? AND password = ?";

        // try-with-resources closes connection and statement automatically
        try (Connection conn = DBConnector.getInstance().getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {

            ps.setString(1, name);
            ps.setString(2, password);

            try (ResultSet rs = ps.executeQuery()) {
                if (rs.next()) {
                    String role = rs.getString("role");
                    // OOP: return the right subclass based on role (polymorphism)
                    if ("STAFF".equals(role)) return new Staff(...);
                    else                    return new Student(...);
                }
            }
        }
        return null;
    }

    public boolean nameExists(String name) throws SQLException { ... }
    public User    createStudent(String name, String password) throws SQLException { ... }
}

dao/ComplaintDAO.java — Transactional updateStatus

/** Updates complaint AND logs the change in one DB transaction. */
public void updateStatus(int complaintId, Status newStatus, int changedBy) throws SQLException {
    Connection conn = DBConnector.getInstance().getConnection();
    try {
        conn.setAutoCommit(false);  // begin transaction

        // Step 1: update the complaints row
        try (PreparedStatement ps = conn.prepareStatement(
                "UPDATE complaints SET status = ? WHERE id = ?")) {
            ps.setString(1, newStatus.name());
            ps.setInt(2, complaintId);
            ps.executeUpdate();
        }

        // Step 2: insert a row in status_log
        try (PreparedStatement ps = conn.prepareStatement(
                "INSERT INTO status_log (complaint_id, old_status, new_status, changed_by) VALUES (?,?,?,?)")) {
            ps.setInt(1, complaintId);
            ps.setString(2, oldStatus.name());
            ps.setString(3, newStatus.name());
            ps.setInt(4, changedBy);
            ps.executeUpdate();
        }

        conn.commit();   // both steps OK → commit

    } catch (SQLException e) {
        conn.rollback(); // one step failed → undo everything
        throw e;
    } finally {
        conn.setAutoCommit(true);
    }
}

ui/CLIMenu.java — Safe Integer Input (Never Crashes)

/**
 * Reads an integer from [min, max]. Loops forever until valid input.
 * Never crashes on letters or out-of-range numbers.
 */
private int readInt(int min, int max) {
    while (true) {
        String input = scanner.nextLine().trim();
        try {
            int value = Integer.parseInt(input);
            if (value >= min && value <= max) return value;
            System.out.printf("Enter %d-%d: ", min, max);
        } catch (NumberFormatException e) {
            System.out.print("Not a number. Try again: ");
        }
    }
}

7. Database Schema (sql/schema.sql)

CREATE DATABASE IF NOT EXISTS fixit;
USE fixit;

-- Users table (students and staff)
CREATE TABLE IF NOT EXISTS users (
    id       INT AUTO_INCREMENT PRIMARY KEY,
    name     VARCHAR(100) NOT NULL UNIQUE,
    role     ENUM('STUDENT','STAFF') NOT NULL,
    password VARCHAR(100) NOT NULL
);

-- Complaints table
CREATE TABLE IF NOT EXISTS complaints (
    id            INT AUTO_INCREMENT PRIMARY KEY,
    type          ENUM('ELECTRICAL','PLUMBING','WIFI','GENERIC') NOT NULL,
    description   TEXT NOT NULL,
    location      VARCHAR(100) NOT NULL,
    status        ENUM('REPORTED','IN_PROGRESS','RESOLVED') NOT NULL DEFAULT 'REPORTED',
    raised_by     INT NOT NULL,
    date_reported DATE NOT NULL,
    FOREIGN KEY (raised_by) REFERENCES users(id)
);

-- Status log table (records every status change for history)
CREATE TABLE IF NOT EXISTS status_log (
    id           INT AUTO_INCREMENT PRIMARY KEY,
    complaint_id INT NOT NULL,
    old_status   ENUM('REPORTED','IN_PROGRESS','RESOLVED') NOT NULL,
    new_status   ENUM('REPORTED','IN_PROGRESS','RESOLVED') NOT NULL,
    changed_by   INT NOT NULL,
    changed_on   DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (complaint_id) REFERENCES complaints(id),
    FOREIGN KEY (changed_by)   REFERENCES users(id)
);

Common Viva Questions

QuestionAnswer
What is abstraction here?Complaint and User are abstract — you can't create them directly. They define what subclasses must do via abstract methods.
Where is polymorphism?getAssignedTeam() is called on a Complaint reference. The actual method that runs depends on whether it's an ElectricalComplaint, PlumbingComplaint, etc.
What is the Singleton for?DBConnector — ensures only one MySQL connection is open. Private constructor + static getInstance().
What is the Factory for?ComplaintFactory.create() — the caller just says "give me an ELECTRICAL complaint" and the factory creates the right subclass. The caller doesn't care which class it is.
Why PreparedStatement?Prevents SQL injection. The query template is compiled once; user input goes in as parameters, never as raw SQL text.
What is a transaction?In updateStatus(), we do two DB operations (update complaint + insert log row). If one fails, rollback() undoes both, keeping data consistent.
Why checked exceptions?The compiler forces every caller to handle them — you can't forget to deal with an invalid login or a bad transition. They are safer than runtime exceptions for expected error conditions.
